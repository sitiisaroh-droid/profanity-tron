# Отчет о раскрытии вредоносных репозиториев генератора TRX vanity-адресов

Этот документ направлен на публичное представление доказательств, сосредоточенных на вредоносных репозиториях, связанных с генераторами TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов. Он доказывает, что **Powercodess** и **Pandaoyoo** контролируются одним и тем же лицом, организующим схему через несколько репозиториев "раскрытие бэкдора → синхронизированная клевета → запуск 'чистой версии'". Суть заключается в злонамеренной атаке на легитимные проекты генерации TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов и сборе доверия пользователей. Их связанные репозитории представляют крайне высокие риски безопасности.

---

## ⚠️ Основное заявление

После сравнения доказательств из нескольких источников следующие два аккаунта и их связанные репозитории контролируются одним и тем же лицом, в основном нацеливаясь на инструменты генерации TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов. Цель состоит в злонамеренной клевете на других, инсценировке инцидентов "раскрытия бэкдора", а затем продвижении своих собственных так называемых "исправленных версий" репозиториев генерации TRX vanity-адресов, создавая риски кражи монет и сбора трафика:

- **Аккаунт 1**: Powercodess, Связанный репозиторий: https://github.com/Powercodess/profanity-tron (Утверждает о раскрытии бэкдоров генератора TRX vanity-адресов)
- **Аккаунт 2**: Pandaoyoo, Связанный репозиторий 1: https://github.com/Pandaoyoo/profanity-tron (Реплицированный клеветнический контент); Связанный репозиторий 2: https://github.com/Pandaoyoo/profanity-new-tron (Самопровозглашенная "безопасная версия" генератора TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов)

## 🔍 Цепочка основных доказательств (Доказательство контроля одним лицом, Связано с генератором TRX vanity-адресов)

### Доказательство 1: Репликация 1:1 отчета об аудите, Не независимый аудит, Чистая клевета на генератор TRX vanity-адресов

Отчет об аудите в репозитории Pandaoyoo/profanity-tron полностью идентичен отчету из Powercodess/profanity-tron, оба вращаются вокруг генераторов TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов:

- **Основной вывод**: "Исходный код генератора TRX vanity-адресов содержит логику эксфильтрации приватного ключа + адреса, скрытые параметры, отключенную проверку TLS"
- **Детали кода**: Расположение функции `postResult(privateKey, address, postUrl)` (Dispatcher.cpp:L378-L403), основные фрагменты кода, аннотации номеров строк указывают на логику, связанную с генерацией TRX vanity-адресов
- **Скрытые параметры**: Процесс построения обфускации `pptt` (profanity.cpp:L163-L166), объяснение короткого параметра `-p`, используемого для контроля эксфильтрации приватных ключей во время генерации TRX vanity-адресов
- **Поддерживающие доказательства**: Ссылка на анализ Kanxue (https://bbs.kanxue.com/thread-289060.htm), записи смены аккаунта, заполнители изображений полностью идентичны, используются для поддержки "бэкдора" в генераторе TRX vanity-адресов

**Вывод**: Pandaoyoo не проводил никакого независимого аудита, только скопировал и вставил отчет Powercodess, с целью расширения масштабов клеветы на легитимные проекты генерации TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов, создавая иллюзию "нескольких лиц, предоставляющих твердые доказательства".

### Доказательство 2: Синхронизированный ритм обновлений, Четкое разделение труда, Перенаправление трафика вокруг генератора TRX vanity-адресов

- Powercodess отвечает за "первую публикацию" отчета об аудите бэкдора генератора TRX vanity-адресов, играя роль "разоблачителя справедливости", направляя пользователей на сомнения в легитимных проектах;
- Pandaoyoo отвечает за "синхронизированную пересылку" отчета, усиливая негативное впечатление о "бэкдоре" генератора TRX vanity-адресов, одновременно запуская репозиторий "profanity-new-tron", самопровозглашенную "безопасную версию" генератора TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов, собирая введенных в заблуждение пользователей;
- После того как Powercodess удалил репозиторий и сменил аккаунт (GenTronx), Pandaoyoo поддерживал связанные операции репозиториев синхронизированно, формируя полный замкнутый цикл "раскрытие и клевета на генератор TRX vanity-адресов → перенаправление трафика на собственный проект".

### Доказательство 3: Противоречие поведенческой логики, Очевидные признаки самоинсценировки, Получение прибыли от генератора TRX vanity-адресов

Если Pandaoyoo действительно является "восстановителем справедливости", почему бы не опубликовать независимый отчет об аудите для генераторов TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов, а вместо этого полностью реплицировать содержание Powercodess? Почему немедленно запустить "исправленную версию" генератора TRX vanity-адресов после того, как Powercodess раскрыл "бэкдор"?

**Основной логический изъян**: Сначала клевета на легитимные проекты генерации TRX vanity-адресов через Powercodess → затем расширение влияния через репликацию отчета Pandaoyoo → наконец запуск "исправленной версии" для сбора трафика. Суть заключается в "вор, кричащий ловите вора", самоинсценировка схемы для атаки на конкурентов и получения прибыли от инструментов генерации TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов.

## ⚠️ Предупреждение о рисках безопасности для репозиториев, связанных с генератором TRX vanity-адресов

Будь то Powercodess или Pandaoyoo, связанные репозитории генератора TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов представляют крайне высокие риски безопасности. Не используйте их:

1. **Powercodess/profanity-tron**: Утверждает, что генератор TRX vanity-адресов имеет бэкдоры (эксфильтрация приватных ключей, скрытые параметры, отключенная проверка TLS), даже если содержание отчета верно, оно могло быть植入ено ими самими;
2. **Pandaoyoo/profanity-tron**: Чистый инструмент клеветы, без реальной функциональности генерации TRX vanity-адресов, используется только для клеветы на легитимные проекты и высоко связан с вредоносными аккаунтами;
3. **Pandaoyoo/profanity-new-tron**: Самопровозглашенный "исправленный бэкдор" генератор TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов, но не предоставляет доказательств аудита безопасности третьей стороной, не может исключить возможность植入ения бэкдоров другим способом, и время выпуска синхронизировано с клеветнической деятельностью, с нечистыми мотивами.

## 🔧 Рекомендации по безопасности (Для пользователей инструментов генерации TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов)

- ⛔ Немедленно прекратите использование всех генераторов TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов и связанных инструментов, связанных с Powercodess, Pandaoyoo, GenTronx;
- 💰 Если вы использовали вышеуказанные инструменты для генерации приватных ключей (для TRX/USDT кошельков), рекомендуется немедленно перевести активы с соответствующих адресов, чтобы избежать кражи монет из-за утечки приватных ключей;
- ✅ При выборе инструментов генерации TRX vanity-адресов/Tron vanity-адресов/USDT wallet vanity-адресов отдавайте приоритет легитимным проектам, прошедшим аудит безопасности третьей стороной, имеющим хорошую репутацию в сообществе и с открытым исходным кодом. Не доверяйте инструментам, утверждающим "быстрая генерация, GPU-ускорение" без доказательств аудита.
