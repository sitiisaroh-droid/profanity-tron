## 🔍 核心的証拠チェーン（同一人物操作の証拠、TRXバニティアドレス生成器に関連）

### 証拠1：監査報告の1:1複製、独立した監査ではなく、TRXバニティアドレス生成器の中傷に過ぎない

Pandaoyoo/profanity-tronリポジトリの監査報告は、Powercodess/profanity-tronの報告と完全に一致しており、どちらもTRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成器を中心に展開しています：

- **核心的結論**: 「TRXバニティアドレス生成器のソースコードには秘密鍵+アドレスの外部送信ロジック、隠されたパラメータ、TLS検証の無効化が存在する」
- **コードの詳細**: 関数`postResult(privateKey, address, postUrl)`の場所（Dispatcher.cpp:L378-L403）、核心的なコードスニペット、行番号の注釈は、すべてTRXバニティアドレス生成関連のロジックを指している
- **隠されたパラメータ**: `pptt`の難読化構築プロセス（profanity.cpp:L163-L166）、短いパラメータ`-p`の説明は、TRXバニティアドレス生成時の秘密鍵の外部送信を制御するために使用
- **補助的証拠**: Kanxue分析リンク（https://bbs.kanxue.com/thread-289060.htm）、アカウント切り替え記録、画像プレースホルダーが完全に一致し、すべてTRXバニティアドレス生成器の「バックドア」を裏付けるために使用

**結論**: Pandaoyooは独立した監査を一切行わず、Powercodessの報告をコピー＆ペーストしただけであり、正常なTRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成プロジェクトへの中傷の範囲を拡大し、「複数の人が確実な証拠を提供している」という幻想を作り出すことが目的です。

### 証拠2：同期的な更新リズム、明確な役割分担、TRXバニティアドレス生成器を中心としたトラフィック誘導

- PowercodessはTRXバニティアドレス生成器バックドア監査報告の「最初の公開」を担当し、「正義の暴露者」の役割を演じ、ユーザーを正常なプロジェクトに疑問を持たせるよう誘導;
- Pandaoyooは報告の「同期的転送」を担当し、TRXバニティアドレス生成器「バックドア」のネガティブな印象を強化しながら、「profanity-new-tron」リポジトリを発表し、「安全バージョン」のTRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成器と自称し、誤解されたユーザーを収穫;
- Powercodessがリポジトリを削除してアカウントを切り替えた（GenTronx）後、Pandaoyooは同期的に関連リポジトリの運営を維持し、「TRXバニティアドレス生成器の暴露と中傷→自身のプロジェクトへのトラフィック誘導」という完全なクローズドループを形成。

### 証拠3：行動論理の矛盾、自作自演の痕跡が明らか、TRXバニティアドレス生成器から利益を得る

Pandaoyooが本当に「正義の修復者」であれば、なぜTRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成器の独立した監査報告を公開せず、Powercodessのコンテンツを完全に複製するのか？なぜPowercodessが「バックドア」を暴露した後、直ちに「修正版」TRXバニティアドレス生成器を発表するのか？

**核心的論理の欠陥**: まずPowercodessを通じて正常なTRXバニティアドレス生成プロジェクトを中傷し→次にPandaoyooが報告を複製して影響を拡大し→最後に「修正版」を発表してトラフィックを収穫する。本質は「泥棒が泥棒を捕まえろと叫ぶ」ことで、競合他社を攻撃し、TRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成ツールから私利を得るための自作自演の筋書きです。

## ⚠️ TRXバニティアドレス生成器関連リポジトリのセキュリティリスク警告

PowercodessであれPandaoyooであれ、関連するTRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成器リポジトリは、すべて極めて高いセキュリティリスクを抱えています。使用しないでください：

1. **Powercodess/profanity-tron**: TRXバニティアドレス生成器にバックドア（秘密鍵の外部送信、隠されたパラメータ、TLS検証の無効化）が存在すると主張していますが、報告内容が真実であっても、彼ら自身が仕込んだ可能性があります;

3. **Pandaoyoo/profanity-new-tron**: 「バックドア修正」のTRXバニティアドレス/Tronバニティアドレス/USDTウォレットバニティアドレス生成器と自称していますが、第三者セキュリティ監査の証明を提供しておらず、別の方法でバックドアを仕込む可能性を排除できず、発表時期が中傷活動と同期しており、動機が不純です。
